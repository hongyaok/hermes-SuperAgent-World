PRODUCT BEHAVIOR

1. One root Superagent session represents one town.
2. Every town begins with:
   - One “Router” house in the center.
   - One pixel-art person associated with the router.
3. When that router spawns a worker session:
   - Create one new house for that exact worker session.
   - Animate the house being constructed or appearing.
   - Add one new person associated with that worker.
4. Support multiple simultaneous worker sessions, each with its own house and person.
5. Clicking the Router house opens the root session’s chat.
6. Clicking a worker house opens that worker session’s chat in a popup.
7. Users can switch towns using a visible town selector and previous/next controls. Switching towns changes only the displayed town; it must not stop or modify any session.
8. Provide a clear “New town” action that creates a real root/router session.
9. Preserve live session states visually. At minimum, distinguish queued, running, review, failed, and cancelled states using badges or small indicators rather than relying only on animation.
